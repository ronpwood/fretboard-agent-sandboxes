# archive/

Retired payload apps, put here by `just app swap` (or `just app archive`) instead of
being deleted. Each entry is `<name>-<timestamp>/`, a straight copy of what used to
live at `apps/<name>/`.

Nothing under here is wired into the factory (ADWs, `just`, `sssf.config.yaml`) — it's
inert history. To bring one back, copy it back into `apps/` and redo the quality.py /
just-recipe wiring the same way you would for any new app.
